# Онлайн-военкомат (курсовая работа по базам данных)

Учебный проект по проектированию и разработке базы данных. Представляет собой веб-приложение на Streamlit, имитирующее базовый функционал военкомата: работу с повестками, данными о здоровье и разграничение прав доступа для двух ролей — военнообязанного (`liable`) и работника военкомата (`worker`).

## Функциональность

### Роль «Военнообязанный» (`liable`)
- Проверка наличия повестки.
- Просмотр собственных данных.
- Добавление информации о состоянии здоровья.

### Роль «Работник военкомата» (`worker`)
- Просмотр и управление повестками.
- Просмотр данных о здоровье.

### Общие страницы
- Вход в систему.
- Регистрация.
- Выход.

## Стек технологий

- **Язык:** Python
- **Веб-фреймворк:** Streamlit
- **СУБД:** PostgreSQL
- **Драйвер БД:** psycopg2
- **Работа с данными:** pandas, numpy
- **Конфигурация:** python-dotenv
